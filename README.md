## Avances

La forma de trabajar es con ramas para la entrega de cada lección y un tema por clase. Proyecto completo: [https://github.com/alexa-coss/web-d-react-avanzado](https://github.com/carlosDevf/DevfSeek).

### Lección 1 - Parte 1: React Hook Form y Validación de formularios avanzada

Rama: parte-1 Descripción: Implementación de formularios en React utilizando React Hook Form y técnicas avanzadas de validación. Usando la IA para crear un front muy básico. Configuración inicial del proyecto, instalación de Tailwind CSS y creación de un diseño básico para la interfaz de usuario.


### Lección 2 - Parte 2: Consumo de APIs (useEffect)

Rama: parte-2 Descripción: Uso de useEffect en React para consumir APIs y manejar datos asíncronos. Crear un custom hook de Ollama y manejo de Ollama.


### Lección 3 - Parte 3: State Management with useContext

Rama: parte-3 Descripción: Gestión del estado global en una aplicación React utilizando el hook useContext.


### Lección 4 - Parte 4: El servidor, ¿qué hay en el back end?

Rama: parte-4 Descripción: Introducción a los conceptos básicos del desarrollo backend y su importancia en una aplicación web. Explicación breve de cómo funcionan los middleware y su utilidad en los servidores.


### Lección 5 - Parte 5: Creando un servidor con Express

Rama: parte-5 Descripción: Creación de un servidor básico utilizando el framework Express de Node.js.


### Lección 6 - Parte 6: Qué es un API REST

Rama: parte-6 Descripción: Explicación y creación de un primer endpoint en Express. Pasar la función de Ollama al servidor como ejemplo inicial de consumo de IA desde el back end.


### Lección 7 - Parte 7: Creando un CRUD Básico con Express

Rama: parte-7 Descripción: Implementación de operaciones CRUD (Crear, Leer, Actualizar, Eliminar) utilizando Express. Usando Lowdb para crear un CRUD completo de las funciones de globalReducer.


### Lección 8 - Parte 8: Servicios de base de datos: MongoDB

Rama: parte-8 Descripción: Implementar Mongo como base de datos. Uso de dotenv: para qué se usa y cómo configurarlo.
